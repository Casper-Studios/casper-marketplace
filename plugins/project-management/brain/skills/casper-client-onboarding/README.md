# casper-client-onboarding

Casper Studios onboarding playbook for new client engagements. Covers everything
from ramping up on a new client to running discovery sessions to handing off to
the engineer.

## When to use

Invoke this skill whenever a PM is:
- Starting a new client engagement or ramping up on an existing one
- Setting up a new project in Linear
- Preparing for a kickoff call or discovery sessions
- Synthesizing post-discovery outputs back into requirements and tickets

Trigger phrases: "help me onboard to [client]", "set up Linear for [project]",
"I have a new engagement", "prep me for discovery", "I just got added to this project".

## What it covers

**Phase 1: Pre-discovery**
- Ingest context from Drive, Slack, Fireflies, and Gmail
- Brief the PM (narrative format, FLAGS section, next moves)
- Build the Kickoff Prep Doc (the single Phase 1 deliverable)
- Email the executive sponsor to set up SME access
- Set up Linear with milestones, tickets, and labels

**Phase 2: Post-discovery**
- Establish the discovery session set from Fireflies
- Profile client data files (data-heavy engagements only)
- Produce the discovery findings export
- Reconcile Linear in one confirmed batch
- Prepare the engineer handoff package

## Engagement types

The playbook forks at the top:
- **DISCOVERY**: find problems, recommend what to build. Default path.
- **BUILD**: a working product exists; harden it and add features. Skip
  problem-discovery; focus on feature prioritization and sequencing.
