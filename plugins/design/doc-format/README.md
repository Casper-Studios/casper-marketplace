# doc-format

Design and document-production skills for Casper Studios.

## Skills

| Skill | Use it for | Output |
|---|---|---|
| `create-ppt` | Casper- or Sphera-branded client decks, proposals, pitches, QBRs, kickoffs, readouts, and weekly updates | Editable `.pptx`, speaker notes, built-in QA, optional review PDF |

[Explore the self-contained create-ppt overview](docs/create-ppt-overview.html) for the workflow, themes,
layout gallery, QA loop, and worked examples.
| `content-generation` | Documents, images, flowcharts, and formatted content | Output varies by request |

## Install

```bash
npx skills add https://github.com/Casper-Studios/casper-marketplace --skill create-ppt
```

Use `site-deck` for an interactive browser presentation and image-first slide tooling for visual panels or
standalone infographics.
